WHAT WE CHANGED

The Lampa you know.
Made multilingual and configurable.

Built on the original Lampa project. Our additions focus on localization, independent Samsung packaging and easier setup — without replacing the original media experience.

文

21 interface languages

From Nederlands and Deutsch to العربية, اردو and हिन्दी. All localizations ship in every WGT and can be changed on the TV.

⇄

RTL-aware design

Arabic, Urdu and Hebrew get directional layouts, font support and isolated technical values — without mirroring posters or video.

▣

Local WGT packaging

Actual app code, language modules and fonts compiled into one Tizen package. No remote main-application loader.

⌘

Visual WGT Builder

A guided local setup: TV language, optional TorrServer URL, parser backend, third-party plugin policy, then build.

◇

Optional TorrServer

Keep the server address empty or preconfigure your own. Parser and server settings remain editable from the TV.

◈

Opt-in plugin catalog

Browse a small categorized extension catalog. Third-party JavaScript is disabled by default and installation requires consent.

NO CLOUD COMPILATION

Build it your way.

Open the local Builder in your browser. The wizard uses the same real compiler as the CLI — without making you type language codes and server settings by hand.

● ● ● macOS / Linux · Node.js 22+
git clone https://github.com/vbrekher/lampa-personal-edition.git
cd lampa-personal-edition
npm ci
npm run builder

The website previews the flow. The actual WGT is created only by the Builder running locally on your computer. Existing CLI users can still run npm run build:personal.

FROM COMPUTER TO TV

Three steps. One WGT.

01

Configure

Choose your initial language and optional TorrServer/parser/plugin preferences in the private local Builder.

02

Compile

Build actual Lampa assets and verify the unsigned WGT package on your computer.

03

Install

Use Apps2Samsung and a Samsung TV in Developer Mode. Signing may be required.

Targets Tizen 5.0+ at source level; real compatibility depends on the Samsung model and firmware. A WGT does not contain movies, streams, a TorrServer service or a VPN.
